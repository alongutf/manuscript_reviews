Eigenvalue z-scores and Gaussian tail probabilities
==============================================================================
source run: eigenvalue_permutation_test_20260823_121230   B=100   ranks 1..20

No distribution is fitted. For each rank k:
  z_k = (lambda_obs_k - mean_k) / sd_k,  moments from the B scrambled draws
  p_k = SF_normal(z_k) = P(X > lambda_obs_k), X ~ Normal(mean_k, sd_k)

The null lambda_1 is asymptotically Tracy-Widom, whose right tail
exp(-(2/3)s^1.5) is HEAVIER than the Gaussian exp(-s^2/2), so p_gaussian
understates the null tail and is anti-conservative -- more so at large z.
skewness / excess_kurtosis / normality_p describe how Gaussian the null
draws actually are. z is assumption-free; only p_gaussian is not.
sd is estimated from B draws, so z carries ~7.1% relative Monte Carlo
error at B=100.
